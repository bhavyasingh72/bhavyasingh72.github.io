Featured Projects
🌿 Automatic Gardening Watering System
IoT-based smart irrigation using soil moisture sensor (YL-69), NodeMCU, and water pump. Monitors real-time humidity and automatically waters plants when dry. Includes Blynk app integration for remote control & data logs. Reduces water waste and ensures optimal plant growth.
🧑‍🦯 Blind Navigation Stick
Arduino Uno based smart walking stick with ultrasonic sensor (HC-SR04), buzzer, and vibration motor. Detects obstacles ahead and provides instant haptic & audio feedback. Enhanced with water detection sensor and GPS module (optional) for safety — an assistive technology innovation.
🔐 Smart IoT Door Lock System
ESP32-CAM based security system with RFID authentication, MQ-5 gas & fire sensor, servo lock, and Blynk dashboard — real-time alerts and facial image capture.
🤖 AI Phone Detection System
YOLOv8 based computer vision model to detect mobile phone usage in real-time, suitable for exam monitoring & safe driving initiatives.
📊 NeuroRevise (AI Study App)
PHP & MySQL web app with performance analytics, weak topic detection and revision suggestions for students — full-stack development project.
💡 Smart Home Automation
IoT based relay-controlled home appliance system using NodeMCU and mobile interface, enabling remote control of lights and fans.
🚗 Bluetooth Controlled Car
Arduino + L298N motor driver with HC-05 module — smartphone-controlled robotic car with smooth maneuverability.
